🌦️ Weatherly – Weather Dashboard

Weatherly is a modern and responsive weather dashboard that provides real-time weather information for cities around the world.

Search for any city and get current weather conditions, temperature, humidity, wind speed, and a 5-day weather forecast — all in one place.

✨ Features

* 🌍 Search weather by city name.
* 🌡️ Display current temperature.
* ☁️ Show real-time weather conditions.
* 💧 Display humidity percentage.
* 🌬️ Show current wind speed.
* 📅 5-day weather forecast.
* 🌙 Light and Dark Mode.
* 🔍 Recent city search history.
* 💾 Save recent searches using Local Storage.
* 📱 Responsive design for different screen sizes.
* ⚡ Free weather API integration.

🛠️ Technologies Used

* HTML5 – Website structure.
* CSS3 – Styling and responsive design.
* JavaScript – Functionality and API integration.
* Open-Meteo API – Weather and geocoding data.
* Font Awesome – Icons.
* Google Fonts – Typography.

🌐 API Used

Weatherly uses the Open-Meteo API to retrieve weather information.

Weather API:
https://open-meteo.com/

Geocoding API:
https://geocoding-api.open-meteo.com/

No API key is required.

🚀 How to Run the Project Locally

1. Clone this repository:

git clone https://github.com/swanandkulkarni10-bot/Weatherly-Weather-Dashboard.git

2. Open the project folder:

cd Weatherly-Weather-Dashboard

3. Open the folder in Visual Studio Code.
4. Open index.html using the Live Server extension.
5. The Weatherly dashboard will open in your browser.

Alternatively, run this command from the project folder:

python3 -m http.server 5500

Then visit:

http://localhost:5500
